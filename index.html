An interactive test of the steering law

Fitts's law predicts how long it takes to point at a target. Many interactions are not about reaching a point but about following a path: drawing a curve, dragging through a cascading menu, moving a slider handle along its track. For these trajectory-based tasks, Accot and Zhai [1997] derived the steering law.

This page lets you run a steering test in the browser, either freely or as a structured experiment, and shows the data from several angles as it comes in. It started out as an interactive illustration of Fitts's law; the tapping task has been replaced by steering tasks. Jump to the test.

The steering law

To steer through a tunnel C whose width W(s) may vary along the path, the movement time MT grows linearly with the integral of the inverse width:

MT=a+b · ∫C ds W(s)

The integral is the task's index of difficulty (ID); a and b are fitted to measured data. This page offers the three tunnels studied in the original work:

Straight tunnel, length A, width W ID=AW
Circular tunnel, radius R, one lap ID=2πRW
Tapered tunnel, width changing linearly from W₁ to W₂ ID=AW1−W2ln⁡W1W2

The page computes the ID of every tunnel by integrating numerically along its centreline, so all shapes share one code path. Two differences from Fitts's law matter for the analysis. The ID is linear in path length over width, not logarithmic, so it has no unit (not bits) and covers a wide range. And errors happen during the movement, when the pointer leaves the tunnel, not at its end.

The steering law follows from a local law: at every point, the speed you can sustain is proportional to the local width of the tunnel,

v(s)= W(s) τ

where τ is a time constant of the person and input device.

The test

Press inside the green start zone, hold the button and drag through the tunnel past the black finish line. For the circular tunnel, steer one full lap back to the green line. Timing starts when you cross the start line and stops at the finish line. Be as fast as you can while staying inside the walls.

Free mode lets you set the tunnel with sliders. Each round has 8 trials in alternating directions, and parameters can be randomised after each round. Experiment mode runs a full design: every combination of the sizes you enter, in random order within each shape, with optional practice. Each run is stored in its own data set.

With the strict error policy, leaving the tunnel ends the trial as an error; in experiment mode it is repeated at the end of its sequence (up to 3 attempts). With the lenient policy, exits are only counted, and the trial goes on to the finish line.

This is a tool for exploring and setting up studies, not a controlled experiment by itself. Sizes are in CSS pixels, so keep the browser zoom at 100 % and use the same screen when you compare data sets. All data stays in your browser (saved automatically) until you export it.

    Evaluating the test data

    The figures below summarise all data sets and update a moment after each trial. Practice trials are left out. Movement times use completed trials; within each condition, times further than 3 standard deviations from the mean are dropped.

    Fig. 2 is the steering law itself: if it holds, the dots of a data set lie on a straight line. Switch to the effective ID to account for how much of the tunnel people actually used. Following Kulikov, MacKenzie and Stuerzlinger [2005], the effective width is We = 4.133 · σ, where σ is the standard deviation of the lateral offset. For tapered tunnels the offset is first divided by the local width, so that We scales with the tunnel along its length. Fig. 3 checks the core claim of the integral form: straight, circular and tapered tunnels with the same ID should take the same time.

    A pointing movement has a bell-shaped speed profile: accelerate, then brake for the target. Steering instead settles on a plateau whose height depends on the width (fig. 6), and that dependence is what fig. 5 measures directly. Fig. 7 compares the width people used with the width they had. Points below the diagonal mean the walls were avoided more than necessary.
